## @nrbx/react-devtools

> Connect to React DevTools by importing.

## Installation

```bash
npm install @nrbx/react-devtools
```

## Usage

```ts
// In your main client script:
import "@nrbx/react-devtools";
```

Importing this package connects your application to the standalone DevTools server with default options. For custom host, port, or profiler settings, use `@nrbx/react-devtools-core` directly.
