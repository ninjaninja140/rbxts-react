## @nrbx/react-devtools-core

> Low-level React DevTools backend API for Roblox.

## Installation

```bash
npm install @nrbx/react-devtools-core
```

## Usage

```ts
import { backend } from "@nrbx/react-devtools-core";

backend.connectToDevtools({
  host: "localhost",
  port: 8097,
  profileOnStart: true,
});
```

## API

- `backend.connectToDevtools(options?)` — connect to the standalone DevTools server
- `ConnectOptions` — `host`, `port`, `useHttps`, `isAppActive`, `profileOnStart`

You usually do not need this package directly. Import `@nrbx/react-devtools` to connect with defaults.
