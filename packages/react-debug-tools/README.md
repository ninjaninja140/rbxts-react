## @nrbx/react-debug-tools

> Hook inspection helpers for debugging React components.

## Installation

```bash
npm install @nrbx/react-debug-tools
```

## Usage

```tsx
import { inspectHooks, inspectHooksOfFiber } from "@nrbx/react-debug-tools";

const tree = inspectHooks(element);
```

## API

- `inspectHooks(element)` — inspect the hooks tree of a rendered element
- `inspectHooksOfFiber(fiber)` — inspect the hooks tree of a specific fiber
- `HooksNode` / `HooksTree` — the shape of the returned hook data
---

Built with [roblox-ts](https://roblox-ts.com)
